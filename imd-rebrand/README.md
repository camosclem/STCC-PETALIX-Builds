# Petalix IMD preview
Petalix is a modified build of [IMD TV by majorleeevil](https://github.com/majorleeevil/imd-tv), based on v0.5.2 at commit `369d43e05ba9de7e5b61fb0621fb7f2bf7558da8`.
The November 19, 2026 changes are the Petalix name and artwork, a separate Android package, Celestial Glass in Dark Mode by default, and removal of the upstream update prompts and install permission.
The app and changes are provided under GPL-3.0. The APK release includes the corresponding source, including upstream attributions and the licence. This source directory contains the changes to apply to upstream.
Use Android TV Settings in the app to add an Xtream, M3U or Stalker playlist. This preview is built for side-by-side installation, with package name `com.petalix.imdpreview`, and is signed with the build runner's debug key.
