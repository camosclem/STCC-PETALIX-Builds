How customers get started

1. Create a master playlist. 2. Add a customer and set the device limit. 3. Send the 8-digit PIN privately. 4. On the new Petalix beta, the customer enters the PIN and downloads the assigned lineup.

The TV app must be built with the HTTPS URL of this deployed control panel. This is a standalone beta backend, not a modification to the old Petalix service.

Setup & Security

Provisioning status

The panel is an independent beta. Nothing is automatically copied from the existing Petalix production backend.

Admin keys and master stream URLs are never committed to GitHub. Customers receive an assigned catalog through a device token after entering their PIN.

Deploy the panel behind HTTPS with persistent SQLite storage and set PETALIX_ADMIN_KEY, PETALIX_PIN_SECRET and PETALIX_FERNET_KEY. Set the TV app's PETALIX_CONTROL_URL to this server URL before distributing a new APK.

This beta supports M3U upload. Xtream server-side provisioning and syncing, EPG management, auto-retries and audit logs need additional work before a customer launch.
